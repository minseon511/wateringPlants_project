### 概要
花卉（かき）農家の小規模事業者のためのAIベースの自律走行型灌水（かんすい）ロボットプロジェクトです。ロボットが農場内を移動しながら植物を認識し、土壌の水分と温湿度を測定して自動で水を供給するシステムです。

---

### 担当役割 (1): 「チャファス」管理ウェブページの開発

**主な機能:**
* **リアルタイムダッシュボード:** 作物別のリアルタイム水分量、時間帯別の温湿度グラフの視覚化。
* **ロボット管理:** ロボットの現在位置、バッテリー状態、水タンク容量のモニタリング。
* **CCTVモニタリング:** 農場およびロボットのカメラ映像をリアルタイムで確認。

**使用技術 (SW):**
* `MQTT` (センサーデータのリアルタイム受信)
* `MySQL` (データベース)
* `Node.js` (Webフレームワーク - 推定)

---

### 担当役割 (2): センサーC++コードの開発

**主な機能:**
* **センサーデータ測定:** `Crowtail 水分センサー`および`DHT11 温湿度センサー`の測定コードを`Arduino C++`で作成。
* **データ通信:** `LOLIN D1 Mini`ボードを使用し、`MQTT`プロトコルでセンサーデータをサーバーに送信。

**使用技術:**
* **HW:** `Raspberry Pi 4/5`, `LOLIN D1 Mini`, `Crowtail-Moisture Sensor`, `DHT11`
* **SW:** `HTML`, `CSS`, `Javascript`, `node.js`, `C++`, `MQTT`
