## プロジェクト紹介

「チャファス(自華水)」は、花卉農家の小規模事業者のためのAIベースの自律走行ロボットです。農場内を自ら移動しながら植物を認識し、土壌の水分と温湿度を測定して自動で水を供給するシステムです。

## 主な機能

* 自律走行 (SLAM): Lidarセンサー(`YDLIDAR X4`)と`ROS 2`を利用して農場の地図を作成(SLAM)し、障害物を回避して走行します。
* AI植物認識: `YOLOv5`ディープラーニングモデルを使用し、カメラで植物の種類をリアルタイムで認識します。
* 自動水やり (灌水): `Crowtail水分センサー`で土壌の水分を測定し、植物ごとの最適な水分量に合わせて自動で水やりを行います。
* 環境モニタリング: `DHT11センサー`で温湿度を測定し、`MQTT`プロトコルを利用して全てのデータをサーバーへリアルタイムで転送します。
* Webダッシュボード: 管理者がWebページを通じて、ロボットの状態、リアルタイムのセンサー値、農場の状況(CCTV)をモニタリングできます。

## 技術スタック (コア技術)

* H/W: `Raspberry Pi 4/5`, `YDLIDAR X4`, `LOLIN D1 Mini`, `水分センサー`, `DHT11 温湿度センサー`
* S/W: `ROS 2 (Foxy/Humble)`, `Python`, `YOLOv5`, `MQTT`, `Ubuntu`
